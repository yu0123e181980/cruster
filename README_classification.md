# 商品自動分類ツール

階層型機械学習を使用した商品自動分類システムです。

## 概要

このツールは、市場データとトライアルマスター（学習データ）を使用して、商品を自動的に階層的なカテゴリーに分類します。

### 主な機能

- **JAN照合**: JANコードによる正確なマッチング
- **階層型機械学習**: カテゴリー → サブカテゴリー → セグメント → サブセグメントの4階層分類
- **精度検証**: 学習データ量に応じた予測精度の可視化
- **信頼度評価**: 予測結果の信頼度を3段階で評価（高/中/低）
- **インタラクティブUI**: フィルター機能とページネーション対応

## 必要なライブラリ

以下のPythonライブラリが必要です：

```bash
pip install flask pandas numpy scikit-learn openpyxl
```

または、requirements.txtを使用：

```bash
pip install -r requirements.txt
```

## 使い方

### 1. アプリケーションの起動

```bash
python app_classification.py
```

起動後、ブラウザで以下にアクセス：
```
http://localhost:5000
```

### 2. データファイルの準備

#### 市場データ（分類対象）
必須カラム：
- **JAN**: 商品のJANコード
- **商品名**: 商品名

任意カラム（精度向上に寄与）：
- 規格
- メーカー
- 容器
- 平均価格
- 既存の分類情報（大分類、中分類、小分類、細分類）

#### トライアルマスター（学習データ）
必須カラム：
- **JAN**: 商品のJANコード
- **商品名**: 商品名
- **規格**: 商品規格
- **メーカー名**: メーカー名
- **カテゴリー名**: 大分類
- **サブカテゴリー名**: 中分類
- **セグメント名**: 小分類
- **サブセグメント名**: 細分類

### 3. 分類処理の実行

1. **市場データをアップロード**
   - ファイルを選択またはドラッグ＆ドロップ
   - カラムマッピングで各項目を選択（JAN・商品名は必須）

2. **トライアルマスターをアップロード**
   - ファイルを選択またはドラッグ＆ドロップ

3. **分類実行ボタンをクリック**
   - 処理が開始され、プログレスバーが表示されます

4. **結果の確認**
   - 統計情報（総件数、JAN一致数、信頼度別の件数）
   - 精度検証グラフ（学習データ量 vs 予測精度）
   - 分類結果テーブル（フィルター・検索機能付き）

5. **結果のダウンロード**
   - 「結果をダウンロード」ボタンでExcelファイルを取得

## 分類アルゴリズム

### 2段階分類プロセス

1. **JAN照合（優先）**
   - トライアルマスターとJANコードで完全一致
   - 信頼度: 100%
   - ステータス: "jan_matched"

2. **階層型機械学習（JANマッチなしの場合）**
   - LinearSVC（サポートベクターマシン）
   - 文字n-gram (2-4文字) による特徴抽出
   - 数値特徴量（価格、容量、入数、メーカーコード）
   - 階層制約：上位階層の予測結果に基づいて下位階層を制約

   信頼度の評価：
   - **高信頼度（70%以上）**: ステータス "ml_high"
   - **中信頼度（40-70%）**: ステータス "ml_medium"
   - **低信頼度（40%未満）**: ステータス "ml_low"

### 階層構造

```
カテゴリー（大分類）
 └── サブカテゴリー（中分類）
      └── セグメント（小分類）
           └── サブセグメント（細分類）
```

## 精度検証機能

学習データを10%-90%の9段階に分割して、各段階での予測精度を検証します。

### 検証項目
- 各階層（カテゴリー、サブカテゴリー、セグメント、サブセグメント）の正答率
- 学習データ量と精度の関係性
- グラフによる可視化

## フィルター機能

結果画面では以下のフィルターが利用可能：

- **検索**: JAN・商品名での部分一致検索
- **ステータス**: JAN一致、高/中/低信頼度でフィルター
- **信頼度**: 信頼度の数値範囲でフィルター
- **表示件数**: 20/50/100件、または全件表示

## データ形式

対応ファイル形式：
- Excel (.xlsx, .xls)
- CSV (.csv) - UTF-8またはShift-JIS

### JANコードの扱い

- 数値として読み込まれた場合でも自動的に文字列に変換
- 末尾の `.0` は自動的に除去
- 前後の空白は自動的にトリミング

## トラブルシューティング

### よくあるエラー

1. **「必須カラムが不足」エラー**
   - トライアルマスターに必須カラムがすべて含まれているか確認
   - カラム名が完全に一致しているか確認（前後の空白に注意）

2. **「クラス数が不足」警告**
   - 学習データの種類（サブセグメント）が1種類しかない場合に発生
   - より多様な商品を含むトライアルマスターを用意

3. **予測精度が低い**
   - トライアルマスターのデータ量を増やす
   - 商品名・規格・メーカーなどの情報を充実させる
   - 既存の分類情報を特徴量として追加

## 技術仕様

- **フレームワーク**: Flask
- **機械学習**: scikit-learn (LinearSVC)
- **データ処理**: pandas, numpy
- **特徴抽出**: TF-IDF (文字n-gram)
- **最大ファイルサイズ**: 50MB
- **推奨学習データ数**: 最低100件以上
