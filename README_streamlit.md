# 商品自動分類ツール - Streamlit版

階層型機械学習（LinearSVC/LightGBM自動切り替え）による商品自動分類システムです。

## 新機能（v2.0）

### 1. アルゴリズム自動切り替え
- **LinearSVC**: 学習データ500件未満
- **LightGBM**: 学習データ500件以上
- サイドバーで手動選択も可能

### 2. 特徴量重要度可視化
- 4階層別に特徴量の寄与度を表示
- インタラクティブな横棒グラフ
- タブで階層を切り替え表示

### 3. SHAP値による個別分析
- 商品を選択してSHAP値を計算
- 予測に影響を与えた特徴を可視化
- ※現在開発中

### 4. 大量データ処理対応
- 100万件の商品データに対応
- バッチ処理（1000件単位）
- リアルタイム進捗表示
- メモリ効率化

### 5. インタラクティブUI
- フィルター・検索機能
- ステータス別表示
- 信頼度スライダー
- ソート・ページング自動対応

### 6. マルチプロセス予測（実験的）
- CPUコア数に応じた並列処理
- プロセス数をスライダーで調整
- 大量データ処理を高速化

### 7. 精度検証（9段階）
- 学習データ10%-90%で検証
- 4階層別の正答率をグラフ表示
- 最高精度時のメトリクス表示

## 使い方

### 1. アプリケーションの起動

```bash
streamlit run app_streamlit.py
```

ブラウザで自動的に開きます（通常は `http://localhost:8501`）

### 2. データの準備

#### 市場データ（分類対象）
必須カラム：
- **JAN**: 商品のJANコード
- **商品名**: 商品名

任意カラム（精度向上）：
- 規格、メーカー、容器、平均価格
- 既存の分類情報（大分類、中分類、小分類、細分類）

#### トライアルマスター（学習データ）
必須カラム：
- JAN、商品名、規格、メーカー名
- カテゴリー名、サブカテゴリー名、セグメント名、サブセグメント名

### 3. 操作手順

#### ステップ1: 設定（サイドバー）
1. **アルゴリズム選択**
   - 自動選択（推奨）
   - LinearSVC（手動指定）
   - LightGBM（手動指定）

2. **並列処理設定**
   - マルチプロセス予測を有効化
   - プロセス数をスライダーで調整

#### ステップ2: データアップロード
1. **市場データをアップロード**
   - ファイルを選択（Excel/CSV対応）
   - カラムマッピングで各項目を指定
   - JAN・商品名は必須

2. **トライアルマスターをアップロード**
   - ファイルを選択
   - 必須カラムの存在を自動確認

3. **分類を実行ボタンをクリック**
   - 処理進捗をリアルタイム表示
   - 完了時にバルーンアニメーション表示

#### ステップ3: 結果の確認
「分類結果」タブで以下を確認：
- 統計情報（総件数、JAN一致数、信頼度別件数）
- フィルター機能
  - 検索: JANまたは商品名で検索
  - ステータス: 複数選択可能
  - 信頼度: スライダーで最低値を指定
- 結果テーブル
  - ソート・フィルタ機能組込
  - 信頼度はプログレスバー表示
- ダウンロード
  - Excel形式で結果を保存

#### ステップ4: 詳細分析
「分析」タブで以下を実施：
1. **特徴量重要度分析**
   - タブで階層を切り替え
   - 横棒グラフで上位20特徴を表示
   - テーブルで詳細確認

2. **SHAP値分析**（開発中）
   - 商品を選択
   - 個別の予測要因を分析

#### ステップ5: 精度検証
「精度検証」タブで以下を確認：
- 学習データ量と精度の関係グラフ
- 4階層別の最高精度メトリクス
- 詳細データテーブル

## 分類アルゴリズム

### LinearSVC
**特徴:**
- 線形サポートベクターマシン
- 小規模データ（< 500件）に最適
- 高速な学習と予測
- 特徴量重要度: 係数の絶対値平均

**使用シーン:**
- 初期データ収集段階
- 迅速なプロトタイピング
- 線形分離可能なデータ

### LightGBM
**特徴:**
- 勾配ブースティング決定木
- 大規模データ（≥ 500件）に最適
- 高精度な予測
- 特徴量重要度: Gain（情報ゲイン）

**使用シーン:**
- 大量の学習データがある場合
- 非線形な関係を捉えたい場合
- 最高精度を追求する場合

### 階層構造
```
カテゴリー（大分類）
 └── サブカテゴリー（中分類）
      └── セグメント（小分類）
           └── サブセグメント（細分類）
```

## 2段階分類プロセス

### 1. JAN照合（優先）
- トライアルマスターとJANコードで完全一致
- 信頼度: 100%
- ステータス: "jan_matched"

### 2. 階層型機械学習
- JAN一致なしの商品に適用
- 文字n-gram (2-4文字) + 数値特徴量
- 階層制約: 上位階層の結果で下位を制約

**信頼度の評価:**
- 高信頼度（≥ 70%）: "ml_high"
- 中信頼度（40-70%）: "ml_medium"
- 低信頼度（< 40%）: "ml_low"

## パフォーマンス

### 処理速度（目安）

| データ量 | アルゴリズム | 処理時間（概算） |
|---------|------------|----------------|
| 1,000件 | LinearSVC | ~10秒 |
| 1,000件 | LightGBM | ~15秒 |
| 10,000件 | LinearSVC | ~1分 |
| 10,000件 | LightGBM | ~1.5分 |
| 100,000件 | LightGBM | ~10分 |
| 1,000,000件 | LightGBM | ~1.5時間 |

### メモリ使用量

- バッチ処理により一定のメモリで処理可能
- 100万件でも8GB以下のメモリで動作

### 大量データ処理のヒント

1. **ファイルサイズ**
   - Excel: 10万行まで推奨
   - CSV: 100万行以上も対応

2. **マルチプロセス**
   - 4コア以上のCPUで有効化推奨
   - プロセス数 = CPUコア数 - 1

3. **バッチサイズ**
   - デフォルト: 1000件
   - メモリが豊富な場合: コード内で調整可能

## トラブルシューティング

### エラー: "LightGBMが未インストール"
```bash
pip install lightgbm
```

### エラー: "SHAPが未インストール"
```bash
pip install shap matplotlib
```

### 処理が遅い
1. マルチプロセスを有効化
2. プロセス数を増やす
3. 不要な任意カラムを削除

### メモリ不足
1. バッチサイズを小さくする（コード修正）
2. CSV形式で出力
3. フィルターで件数を絞ってからダウンロード

### 精度が低い
1. トライアルマスターのデータ量を増やす
2. 商品名・規格・メーカーなどの情報を充実
3. 既存の分類情報を特徴量として追加
4. LightGBMを使用（500件以上の場合）

## 技術仕様

- **フレームワーク**: Streamlit

- **推奨学習データ数**: 100件以上
