# 商品自動分類ツール（Streamlit版）

食品小売業のカテゴリーマネジメント専門の商品自動分類システムです。

## 特徴

- **Node.js完全不要**: Python + Streamlitのみで動作
- **アルゴリズム自動切り替え**: LinearSVC（<500件） / LightGBM（≥500件）
- **階層型分類**: カテゴリー → サブカテゴリー → セグメント → サブセグメント（4階層）
- **JAN一致判定**: 機械学習予測の前にJANコードで直接マッチング
- **大量データ対応**: 100万件規模のデータを処理可能
- **マルチプロセス**: CPUコア数に応じた並列処理
- **精度検証**: 9段階クロスバリデーション
- **特徴量重要度**: 階層別の可視化
- **SHAP値**: 個別商品の予測説明性分析

## システム要件

- Python 3.9以上
- メモリ: 最低4GB（推奨8GB以上）
- CPU: マルチコア推奨

## セットアップ

### 1. 仮想環境の作成

```bash
# Linuxの場合
python3 -m venv venv
source venv/bin/activate

# Windowsの場合
python -m venv venv
venv\Scripts\activate
```

### 2. 依存関係のインストール

```bash
cd product-classification
pip install -r requirements.txt
```

### 3. アプリケーションの起動

```bash
streamlit run app.py
```

ブラウザで自動的に `http://localhost:8501` が開きます。

## 使い方

### 1. データの準備

#### 市場データ（分類したいデータ）
必須カラム:
- `JAN`: JANコード（13桁または8桁）
- `商品名`: 商品名

任意カラム:
- `規格`: 規格（例: 500ml）
- `メーカー`: メーカー名

#### トライアルマスター（教師データ）
必須カラム:
- `JAN`: JANコード
- `商品名`: 商品名
- `category`: カテゴリー
- `subcategory`: サブカテゴリー
- `segment`: セグメント
- `subsegment`: サブセグメント

任意カラム:
- `規格`: 規格
- `メーカー`: メーカー名

### 2. ファイルのアップロード

1. 市場データをアップロード（CSV/Excel対応）
2. トライアルマスターをアップロード（CSV/Excel対応）

### 3. カラムマッピング

- 各カラムを対応する項目にマッピング
- 自動検出機能により、一般的なカラム名は自動で選択されます

### 4. 設定（サイドバー）

- **アルゴリズム**: 自動選択（推奨）/ LinearSVC / LightGBM
- **マルチプロセス**: 有効/無効、プロセス数の設定
- **出力形式**: CSV（推奨）/ Excel

### 5. 分類実行

「分類開始」ボタンをクリックして処理を開始します。

### 6. 結果の確認

#### 統計情報タブ
- 総件数、JAN一致率、信頼度別の件数
- 平均信頼度

#### 精度検証タブ
- 学習データ量と精度の関係（9段階）
- 階層別の精度推移グラフ

#### 特徴量重要度タブ
- 各階層ごとの特徴量重要度
- 横棒グラフで可視化

#### 結果一覧タブ
- 分類結果の一覧表示
- フィルタ・検索機能
- CSV/Excelダウンロード
- SHAP値による個別商品分析

## アルゴリズムの選択

### LinearSVC
- **推奨**: 学習データ500件未満
- **特徴**: 高速、メモリ効率が良い
- **用途**: 小規模データセット

### LightGBM
- **推奨**: 学習データ500件以上
- **特徴**: 高精度、大規模データに対応
- **用途**: 中〜大規模データセット

### 自動選択（推奨）
学習データの件数に応じて自動的に最適なアルゴリズムを選択します。

## 信頼度の判定基準

- **JAN一致**: 信頼度100%（トライアルマスターと完全一致）
- **高信頼度**: 信頼度80%以上（機械学習予測）
- **中信頼度**: 信頼度50-80%（機械学習予測）
- **低信頼度**: 信頼度50%未満（機械学習予測、要確認）

## パフォーマンス最適化

### 大量データ処理
- 100万件規模のデータに対応
- バッチ処理（1000件単位）
- ストリーミングCSV書き込み

### マルチプロセス
- CPUコア数に応じた並列処理
- 推奨プロセス数: CPUコア数 - 1

### メモリ管理
- 明示的なメモリ解放
- ガベージコレクション実行
- 大量データ時の警告表示

## トラブルシューティング

### エラー: ファイル読み込み失敗
- エンコーディング: UTF-8、Shift-JIS、CP932などを自動試行
- 対処: ファイルをUTF-8で保存し直す

### エラー: メモリ不足
- 対処1: マルチプロセスを無効化
- 対処2: データを分割して処理
- 対処3: CSV形式で出力（Excelより軽量）

### エラー: モデル学習失敗
- 原因: トライアルマスターが少なすぎる
- 対処: 最低10件、推奨100件以上のトライアルマスターを用意
